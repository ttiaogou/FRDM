## 实施门禁

1. 核对仓库、授权的 PP 分支与最新提交；本地执行场景还应核对工作区状态。所有代码任务必须执行第 0 节约束。
2. 先审计无障碍入口→事件归一化→页面观察→任务协调→UI/手势执行→结果核验，并区分现有实现与目标规范。
3. 只修改明确授权的范围，不私自改变算法、重试节奏、输入规则、指纹结构、默认值和现有测试。
4. 本轮节点检索保留有限次局部重试，外层未知页恢复继续受控退避；手势可视化执行前核查可用性，失效时受控恢复或阻断本次手势。
5. 修改后核对文件差异、验证结果、未验证项目；不得将文档要求冒充已实施的运行时功能。
